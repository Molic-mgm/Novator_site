# Структура сайта Novator

## Основные разделы
- Главная (`/`)
- Смены (`/shifts`)
- О лагере (`/about`)
- Программы (`/programs`)
- Родителям (`/parents`)
- Команда (`/team`)
- Галерея (`/gallery`)
  - Альбом (`/gallery/:id`)
- Документы (`/documents`)
- Вакансии (`/vacancies`)
- Контакты (`/contacts`)
- Бронирование (`/booking`)

## Админ-панель
- Смены (`/admin`)
- Контент (Home) (`/admin/content`)
- Структура сайта (`/admin/site`)
- Контакты (`/admin/contacts`)
- Команда (`/admin/team`)
- Галерея (`/admin/gallery`)
- Вакансии (`/admin/vacancies`)
- Заявки (`/admin/bookings`)
- Пользователи (`/admin/users`)
- Лог действий (`/admin/audit`)

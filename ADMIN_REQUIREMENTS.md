# Требования к админ-панели Novator

## 1) Общие требования к админке

Админ-панель должна позволять:

- добавлять/редактировать/удалять любой контент на сайте;
- менять порядок отображения элементов;
- включать/выключать блоки и страницы;
- загружать медиа (фото, видео, файлы);
- редактировать меню и подменю;
- управлять заявками и сменами;
- **никакие изменения контента не должны требовать вмешательства разработчика.**

## 2) Что конкретно должно редактироваться

Ниже — чёткий перечень объектов, которыми нужно управлять из админки.

### 2.1 Раздел «О лагере»

Через админку должны редактироваться:

- тексты блоков:
  - месторасположение
  - безопасность
  - проживание
  - питание
  - медобслуживание
  - распорядок дня
- изображения к каждому блоку;
- порядок блоков на странице;
- включение/выключение отдельных разделов.

### 2.2 Раздел «Команда»

Для каждого сотрудника админка должна позволять:

- добавлять/редактировать сотрудника;
- указывать:
  - ФИО
  - должность
  - краткое описание
  - подробное описание
- загружать короткое видео для карточки сотрудника;
- (опционально) загружать постер/кадр для превью;
- управлять порядком сотрудников;
- скрывать/показывать сотрудника на сайте.

### 2.3 Вакансии

В админке:

- создание вакансий;
- редактирование описаний;
- публикация/скрытие;
- просмотр откликов на вакансии.

### 2.4 Галерея (фото + видео)

Админка должна позволять:

- загружать:
  - фото
  - видео
- создавать категории галереи;
- распределять материалы по категориям;
- менять порядок элементов;
- удалять/скрывать материалы;
- **фото и видео находятся в единой галерее.**

## 3) Раздел «Смены» – полная управляемость

### 3.1 Каталог смен

В админке должно быть возможно:

- добавлять новую смену;
- редактировать:
  - название
  - даты
  - цену
  - описание
  - обложку
  - галерею смены
- включать/выключать смены;
- помечать как архивные;
- менять порядок отображения.

### 3.2 Главный экран смен

- возможность загрузить главное фото раздела (вместо градиента);
- менять фон/обложку в один клик.

### 3.3 Заявки

- просмотр всех заявок;
- фильтрация по сменам;
- экспорт заявок;
- отметка «обработано».

## 4) Раздел «Программы»

Через админку:

- редактирование описаний всех 4 программ:
  - воспитательная
  - физкультурно-оздоровительная
  - образовательно-развивающая
  - интеллектуально-развлекательная
- добавление направлений внутри программ;
- загрузка фото к каждому направлению;
- изменение порядка блоков.

## 5) Раздел «Родителям»

В админке должны редактироваться:

- все тексты подразделов:
  - медтребования
  - необходимые документы
  - сертификаты
  - правила поведения
  - правила посещения
  - списки «можно / нельзя / по согласованию»
- возможность:
  - менять формулировки
  - добавлять пункты
  - загружать сопутствующие файлы

## 6) Раздел «Документы»

Через админку должно быть возможно:

- загружать/заменять файлы:
  - Лицензия
  - СЭЗ
  - Программа госгарантий
  - любые другие документы
- менять:
  - название документа
  - описание
  - дату
- удалять устаревшие файлы;
- **раздел «Документы» должен быть полностью динамическим.**

## 7) Контакты

Редактируемые из админки:

- адрес;
- телефоны;
- почта;
- ссылки на мессенджеры;
- реквизиты;
- карта/координаты;
- текст на странице.

## 8) Меню и структура сайта

Через админку должно быть возможно:

- редактировать пункты меню;
- включать/выключать страницы;
- менять порядок разделов;
- добавлять новые страницы при необходимости.

## 9) Права доступа и безопасность

В админке необходимо:

- авторизация по логину/паролю;
- роли пользователей (минимум):
  - администратор
  - редактор
- логирование действий:
  - кто
  - когда
  - что изменил

## Итоговое обязательное требование

Сайт должен быть реализован так, чтобы любой контент и документы можно было менять самостоятельно через админку без участия разработчика.
